# projectsubthree.com

The landing page and future home of Project Sub Three — an AI training companion for runners chasing the sub-three marathon.

## Local development

Open `index.html` in a browser. That's it.

## Deployment

This site is designed to deploy on [Vercel](https://vercel.com) as a static site. Connect this repo and set the root directory to `./` (or wherever `index.html` lives).
